    What Verisafe can and cannot tell you

    • Verisafe looks for warning signs. It cannot prove a file is safe.
    • A low result means nothing suspicious was found, not that the file is clean.
    • With only a name and link, it checks the name, the link, and common tricks like fake brand sites.
    • If you choose the file, it also checks the file’s first bytes, plus risky features in PDFs and scripts.
    • Your file is read inside your browser and is never uploaded anywhere.
